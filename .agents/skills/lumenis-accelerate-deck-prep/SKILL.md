# Accelerate deck prep

Owner: Ted (content).
Status: draft procedure, written 2026-10-29 from the Vision Accelerate planning session. Ted has a working local agent for most of this; merge its tested steps into this file before first use. Review required.

## Inputs

- The session line-up from Smartsheet (C9): sessions, presenters, rooms.
- The OneDrive standard decks for each session type (for example DMST, DMST Decoded, the medical model session).
- The **master KOL slide repository** deck: every KOL bio and case-study slide we have made.
- The [KOL library](../../../assets/kol-library/index.md) for names, credentials and approved bios.
- New KOLs' interview notes (K6), when any.

## Procedure

### C10 Session decks (T-12)

1. **Start from the standard deck** for each session; never from a past show's edited copy.
2. **Presenters:** for each deck, insert the bio and case-study slides of the KOLs presenting it, from the master repository, and remove anyone who isn't presenting.
3. **New KOL:** build their bio slide and case-study slide in the standard slide design (same layout for every KOL), from the library entry and interview notes. Add both to the master repository deck and to the OneDrive standard decks, so the next show starts with them.
4. **Raffle slide:** insert at the point in the session where the raffle happens. The slide says winners must be present.
5. **Check** each deck with the deck rows of [lumenis-webinar-asset-check](../lumenis-webinar-asset-check/SKILL.md) (claims, references, safety text, KOL details, brand, images); skip the ON24 row.
6. **Upload** finals to the event's Dropbox folder for the run of show ([lumenis-run-of-show](../lumenis-run-of-show/SKILL.md)). Replacing a file later means uploading over the same file.

### C15 Leadership decks (T-12)

Ted owns the leadership opening deck and the sales kickoff deck. Start from the last show's versions; update city, date, attendance and pipeline figures from the attendee report and pipeline sync (S1, S3). Send to the presenting executive for review; upload the approved files to Dropbox.

### Then

The KOL session briefs go out with [lumenis-accelerate-kbyg-emails](../lumenis-accelerate-kbyg-emails/SKILL.md) (C11), using the Dropbox links recorded in Smartsheet.

## Boundaries

- Patient images need documented consent; no new clinical claim without the claims check.
- Decks and the slide repository live in OneDrive and Dropbox, never in this repository.
