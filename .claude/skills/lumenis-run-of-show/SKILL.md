# Run of show

Owner: Kaelyn (event logistics), with Ted for decks and media.
Status: draft procedure, written 2026-10-29 from the Vision Accelerate planning session; not yet run. Review required.

The AV lead runs every room from one document. They get every deck, including breakouts: their team takes a laptop to each breakout room with the right files. A run of show that changes after files are downloaded breaks that, so the rule is **replace files, never re-link**.

## Inputs

- The run-of-show template (marketing leadership's version, stored in Smartsheet with the event templates). If it isn't in Smartsheet yet, ask for it and store it there first.
- The event's session schedule and room plan from Smartsheet (session line-up, C9; room map, E1).
- Deck and video files in the event's Dropbox folder (deck prep, C10 and C15).

## Build (start at T-14, final by T-4)

1. **Copy the template** into the event folder as `<Event> Run of Show`.
2. **Grid:** one row per time slot, one column per room (main stage, each breakout, demo rooms). Each cell holds the session title, presenters, and the media to play (deck, videos, walk-in or walk-out music).
3. **Links:** each media item links to its Dropbox file. Use Dropbox's view link for the file, not a folder link, and open every link once.
4. **Check against the schedule:** every session in the agenda appears once, in the right room and time; no presenter is in two rooms at once.
5. **Share** the sheet with the AV lead and the on-site marketing leads (viewer access).

## Changes after sharing

- Replace a deck by uploading the new version **over the same Dropbox file** so the link doesn't change. Never add a new file and swap the link.
- Change a cell's time or room only with a note in the row comments; tell the AV lead the same day.
- Ask the AV lead not to download files until the day before the show, so last-minute replacements land.

## Final check (T-4, Monday before the show)

Every link opens; every deck is the current version; the AV lead has confirmed receipt. Record the sheet link in Key Info.

## Boundaries

- The run of show is the operational record; nothing from it goes into this repository.
- Ask before deleting a session from the grid; mark it cancelled instead.
